# MiniCrit-1.5B  
### Adversarial Financial Critic Model for Autonomous LLM Trading Systems

---

## Overview

MiniCrit-1.5B is an adversarial LLM critic designed to validate, rebut, and stress-test financial reasoning within multi-model trading systems.

This project includes:

- FinRebut-600 dataset  
- LoRA critic checkpoint  
- ATAC-LoRA training scripts  
- Zenodo DOI + ORCID integration  
- Forward testing performance
