# MiniCrit-1.5B

Welcome to the official documentation & research page for **MiniCrit-1.5B**, an adversarial financial critic model for LLM trading systems.

## 🚀 Quick Links
- GitHub Repo  
- Dataset (HuggingFace)

## 🧠 About
MiniCrit-1.5B evaluates LLM-generated trading rationales and produces adversarial rebuttals to catch weak reasoning before execution.

## 📊 Dataset
FinRebut-600 — a curated dataset of human-style rationales and adversarial counter-arguments.
