# Contributing to MiniCrit-1.5B

Thank you for your interest in contributing!  
MiniCrit is an independent research project focused on building adversarial financial critic models and high-quality datasets for LLM trading systems.

All contributions are welcome:
- New rationale/rebuttal samples  
- Dataset cleaning or augmentation  
- Improvements to the ATAC-LoRA training pipeline  
- Checkpoints, reproducibility fixes, benchmarking code  
- Documentation, diagrams, issue reports, feature suggestions  

---

## 🧩 How to Contribute

### 1. Fork the repo
https://github.com/wmaousley/MiniCrit-1.5B/fork


### 2. Create a feature branch
git checkout -b feature/my-improvement

shell
Copy code

### 3. Commit clean changes
Follow the style:
Add: <description>
Fix: <description>
Docs: <description>

### 4. Open a Pull Request  
Provide:
- Summary of changes  
- Why they help the project  
- Any performance or reproducibility notes  

The maintainer (William Ousley) will review PRs as time permits.

---

## 🧪 Adding New Data (High Impact)

If contributing to **FinRebut-600** or future datasets:

- Add examples in the CSV format  
- Include `rationale`, `rebuttal`, `label`  
- Use realistic financial reasoning (no hallucinations)  
- Avoid copying proprietary content  
- Keep writing natural and human-like  
- 3–7 sentence structure works best
